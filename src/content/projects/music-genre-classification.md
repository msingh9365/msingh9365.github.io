## Overview

An end-to-end music genre classifier built on the **GTZAN** dataset. The project compares several classic machine learning and deep learning techniques side by side.

## Approach

- **Feature engineering** on audio with **Librosa**.
- Models trained with **scikit-learn** and **PyTorch**.
- In-depth evaluation to compare how each technique performs.
