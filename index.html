Case Study · Computer Vision

Multi-Paradigm CBIR

Jan 2026 – May 2026

Content-based image retrieval usually picks one paradigm and moves on. This project instead ran a controlled comparison across six retrieval paradigms — Local Binary Patterns, a 21-dim HSV/LAB/RGB color descriptor, a shallow fully-connected net, a deeper net, pretrained ResNet-18 features, and a novel 76-dim MSTE-RG descriptor I designed, combining multi-scale texture, spatial edge density, DCT coefficients, and a Radial Gradient Energy Profile — to see where handcrafted features still hold up against deep CNN embeddings.

Evaluated via Precision@K, Recall@K & mAP on CIFAR-10, MNIST & Fashion-MNIST · served via an interactive Gradio dashboard

Case Study · NLP / Data Engineering

YouTube Trend & Sentiment Analysis

Jan 2026 – May 2026

A three-stage PySpark pipeline that turns raw, state-wise YouTube video and comment dumps into a queryable trend dashboard. Raw data is cleaned and validated, then run through a multilingual NLP stage — Sentence-BERT embeddings, KeyBERT keyword extraction, VADER sentiment scoring, and FLAN-T5 summarization — before being aggregated into state-level topic tables on Delta Lake and surfaced through a Streamlit dashboard.

Containerized with Docker · Delta Lake on S3-compatible object storage
